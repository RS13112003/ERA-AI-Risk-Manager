# Dataset Guide

## Training
`training/creditcard.csv`
Original dataset used for model development and training.

## Demo
Datasets in `demo/` are provided so users can test the
deployed application without needing to find or prepare
their own transaction data.

These datasets are NOT used to train the final model.

## Held-out
Datasets in `heldout/` are kept separate from training
for evaluation/diagnostic purposes.
