# Dataset Guide

## Training

The original training dataset used for model development and training is the **Credit Card Fraud Detection** dataset from Kaggle.

**Source:** [Kaggle — Credit Card Fraud Detection](https://www.kaggle.com/datasets/mlg-ulb/creditcardfraud)

The original `creditcard.csv` file is not included in this repository due to its large file size. Please download it directly from the Kaggle source if you need the original training dataset.

## Demo

Datasets in `demo/` are provided so users can test the deployed application without needing to find or prepare their own transaction data.

These datasets are NOT used to train the final model.

## Held-out

Datasets in `heldout/` are kept separate from training for evaluation/diagnostic purposes.
